# visual-cataloguer

Batch catalogue physical collections using visual dividers (QR codes) and automated image processing.

## Quick Start

```bash
# Install with uv
uv sync

# Run the CLI
uv run viscatalog --help
```

## Development

```bash
# Run tests
uv run pytest

# Type checking
uv run mypy cataloguer

# Linting
uv run ruff check cataloguer
```
